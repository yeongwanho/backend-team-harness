# Contributing

Backend Team Harness is intentionally small while its contracts are being proven.

1. Open an issue describing the backend workflow problem, not only the proposed feature.
2. Add or update tests before changing a command contract.
3. Keep company-specific rules in a separate private project pack.
4. Run `npm test` and `npm run check` before sharing a change.

Do not include private repositories, tickets, access tokens, production logs, customer data, or internal URLs in examples or test fixtures.
